Step 1: Install and Launch Ubuntu 22.04 on Windows (WSL2)
ROS 2 Humble only supports Ubuntu 22.04 LTS (Jammy Jellyfish). Even if you already have another Ubuntu version installed in WSL, you must install and launch the Ubuntu-22.04 distribution specifically so the ROS 2 packages install without dependency errors.

Open Windows PowerShell as Administrator and run:

PowerShell
wsl --update
wsl --install -d Ubuntu-22.04
If prompted, restart Windows. Once the Ubuntu 22.04 terminal window opens, enter a lowercase Linux username and password.

Anytime you open PowerShell or Windows Terminal later, start this specific environment by running:

PowerShell
wsl -d Ubuntu-22.04
Verification: Inside the Ubuntu terminal, check that your version is 22.04 and update the base packages:

Bash
lsb_release -a
sudo apt update && sudo apt upgrade -y
Confirm the output displays Release: 22.04 and Codename: jammy.

Step 2: Install ROS 2 Humble, Gazebo, and Python Libraries
Run the following block inside your Ubuntu 22.04 terminal to add the official ROS 2 package repository and install ROS 2 Humble Desktop, Gazebo 11, and the required Python libraries:

Bash
# 1. Configure locale and add the ROS 2 apt repository
sudo apt install -y software-properties-common curl locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

sudo add-apt-repository universe -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# 2. Install ROS 2 Humble, Gazebo Classic, and Python tools
sudo apt update
sudo apt install -y \
  ros-humble-desktop \
  gazebo11 \
  ros-humble-gazebo-ros-pkgs \
  ros-humble-dynamixel-sdk \
  ros-humble-turtlebot3-msgs \
  ros-humble-turtlebot3 \
  python3-colcon-common-extensions \
  python3-rosdep \
  python3-numpy \
  python3-matplotlib \
  python3-yaml \
  python3-pip \
  git
(sudo apt update

sudo apt install -y \
  ros-humble-desktop \
  ros-humble-ros-gz \
  ros-humble-dynamixel-sdk \
  ros-humble-turtlebot3-msgs \
  ros-humble-turtlebot3 \
  python3-colcon-common-extensions \
  python3-rosdep \
  python3-numpy \
  python3-matplotlib \
  python3-yaml \
  python3-pip \
  git)
  
  
# 3. Initialize rosdep (safe to ignore if already initialized)
sudo rosdep init || true
rosdep update
